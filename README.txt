RAKEEN — ONLINE ADMIN + APPOINTMENT VERSION

WHAT IS INCLUDED
- Customer website (index.html)
- Online products database (Supabase)
- Online appointment database (Supabase)
- Admin panel for adding/deleting products and viewing appointments
- Mobile responsive design

SETUP
1. Create a FREE project at https://supabase.com/
2. In Supabase SQL Editor, paste and run database.sql.
3. In Supabase Project Settings > API, copy the Project URL and anon/public key.
4. Put them in config.js.
5. Change ADMIN_PASSWORD in config.js.
6. Upload index.html, config.js and database.sql to your hosting.

IMPORTANT SECURITY NOTE
The included admin gate is a quick prototype. For a real business launch, use Supabase Auth and Row Level Security so customers cannot access admin data or modify products. Do NOT put a service_role/secret key in config.js.

GOOGLE
Google Search does not host websites. Put the site on a web host (GitHub Pages, Cloudflare Pages, etc.) and optionally buy/connect a domain such as rakeen.in. Google can then index the public site after it is live.
